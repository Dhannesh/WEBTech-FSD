# Units in CSS

1. px -> border, font
   works almost everywhere, can be set with border, image,
2. vw (view Width), vh (view Height) -> it always relate to screen view size
3. % -> relate to its parent
4. em -> related to its parent
5. rem -> related to main (related to root)

## Standard Font size of headings
