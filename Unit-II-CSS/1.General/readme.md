# CSS

Cascade Style Sheet

## No of to use CSS in html file

1. Inline - when style added in same html file with style attribute
2. Internal - when style is define in same page at head section
3. External - when style is in external file and liked in head section of html file by using link tag

## Priority

> follow cascade (top to bottom) and override existing styles if same style is defined

## Insert favicon

we generally add in to head section with link tag
