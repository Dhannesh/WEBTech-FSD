# CSS Position

1. static - bydefault
2. relative - to parent, left, right, top, bottom , value can be -ve and +ve
3. absolute - bydefault parent of absolute element is root if no any relative element, otherwise it will be relative to their parent
4. fixed - fixed to the screen, relative to root
5. sticky - relative to parent,
6. z-index - depends on value, so show element one on above, by default value of z-index is zero for all html elements
